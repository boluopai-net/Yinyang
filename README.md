# 阴阳 · Yinyang

![用尽量少的复杂性辅助个人获得个人观点、工作模型以及个人 RSI 的全局提示词形式。四条主线为容纳不一致语义、阴阳辩证法、圣状与三位一体、个人递归自改进。](assets/yinyang-cover.zh-CN.png)

递归自改进（RSI）指的是，产生改进的方法本身也能得到改进。这本文集讨论怎样让人和模型一起工作的环境随实践改变。

## 阅读与使用

想读论证，可以从[《借火》](docx/references/docs/stealing-fire.zh-CN.md)开始。想直接试用，可以从自己的哲学写作、个人材料和印象中选出认可的观点。这里的「哲学写作」取广义：一篇生活随笔或工作复盘，只要写出了你怎样看待一个问题，就可以作为材料。请模型把你们怎样工作写成六份描述，再用它们调整自己的软件环境。实际使用中遇到的困难，可以回来修订这些观点、描述和工具。
