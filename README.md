递归自改进（RSI）指的是，产生改进的方法本身也能得到改进。这本文集从四个问题出发，讨论怎样让人和模型一起工作的环境也能随实践改变。

| 想弄明白的问题 | 对应文章 |
| --- | --- |
| 材料相互矛盾时，哪些结论还有根据？ | [容纳不一致语义](docx/references/docs/inconsistency-tolerant-semantics.zh-CN.md) |
| 我先提出一个直觉，模型可以怎样帮我检验它？ | [阴阳与太极](docx/references/docs/yinyang-and-taiji.zh-CN.md) |
| 一篇作品、一个伙伴、一套工具怎样支持我持续做一件事？ | [书写自己的圣状](docx/references/docs/writing-a-sinthome.zh-CN.md) |
| 一次修改怎样让下一次修改做得更好？ | [用文学书写自己的递归改进](docx/references/docs/literary-recursive-improvement.zh-CN.md) |

## 选择怎样阅读与使用

想读论证，可以从[《借火》](docx/references/docs/stealing-fire.zh-CN.md)开始。想直接试用，可以从自己的材料里选出认可的观点，请模型把你们怎样工作写成六份描述，再用它们调整自己的软件环境。实际使用中遇到的困难，可以回来修订这些观点、描述和工具。
