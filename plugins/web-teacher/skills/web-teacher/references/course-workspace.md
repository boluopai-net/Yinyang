# Course workspace

First apply the root's study-mode distinction. A philosophical book collection
is not a missing technical course: resolve its independent glossary and connected
argument/research guide through the philosophy and materials branches. Do not
initialize per-book plans, progress files, exercise inventories or checkpoints
to make that collection resemble a course. The compilation below applies when
an actual course mapping is being created or repaired.

Use this branch when creating or repairing a selected course mapping or when
entry or resumption of an existing mapped course depends on resolving a source,
workspace or recovery gap. Inspect the mapping, resolver, and actual sources
and artifacts relevant to the gap. Use existing State for learner recovery and
inspect answer, practice or workspace inventory where the selected activity uses
it. The root router selects the path and materials branches when the work needs
mapping decisions or saved-material writes.

The workspace gives a proposed course mapping a body in accessible sources,
artifacts, and entries. Its resolver connects that proposal to what actually
exists; learner evidence later tests whether the material carries the intended
modeling responsibility. These are separate checks, so a complete folder or
prepared checkpoint cannot certify a learner outcome.

## Compile real course facts

When compiling a mapping, specify entry and re-entry, downstream responsibility,
intended exit or transfer evidence, source order, retained depth, and what would
warrant revisiting omitted modules or revising the mapping. Include local-practice
triggers where used. When the mapping or an actual assessment calls for a
checkpoint, bind it to the source boundary, the learner contribution sought and
accessible answers or evaluation criteria. Inspect actual assignment and
workspace constraints alongside the learning goal. Static cards supply
hypotheses; actual materials and learning evidence determine traversal and
repair. Preserve the established book or lecture order and keep per-turn
choices within the current guide.

Create or repair the course-local resolver when actual sources, artifacts,
inventory or workspaces would otherwise be ambiguous. The recipient's resolver
records paths, editions, source roles and conditional use. Resolve
existing notes and learner-authored content first. The materials branch owns the
glossary, main guide, technical training and gradual integration of existing
plan, practice or reading references. Record the maintained entrypoint and link
the resources available for this work.

Create Course State when an actual teaching encounter or attributable learner
history needs recoverable continuation, using the root's State contract. A
materials-only preparation task records its readiness in the existing material
index or maintenance record, without creating empty learning State. When State
is warranted, distinguish no evidence from failure. A complete workspace or
successful source check does not establish learner understanding.

## Validate the course mapping and materials

Resolve the affected paths and source editions. For a mapping or source repair,
verify order and inspect actual coverage of prerequisites. For a selected
checkpoint, verify scope and answer or evaluation evidence. Where guide or
training changes affect an activity, check that its route and allocation match
the actual inventory. Resolve prepared exercises and recorded attempts before
assigning another item. Update training when the source pool or usable scope
changes.

Check glossary source sequence, recall purpose, supported coverage and preserved
reading layers; check continuity and manageable load in reading selections.
Keep skimming exposure distinct from detailed coverage and mastery. Validate
changed saved materials using the materials branch’s actual reading-mode and
navigation checks, including when app-native tools are needed. Static link
resolution alone cannot establish a usable rendered result.

At a mapped local-practice trigger, surface the exact item/slice, value,
allocation, learner reasoning, operation, expected evidence and workspace entry.
The root's independent local-execution boundary still applies. If inventory or
source access remains missing or ambiguous, name the precise limit and continue
only with supported work. Broader mapping failures follow the path branch's
audit boundary; do not invent a course mapping to complete the folder.
