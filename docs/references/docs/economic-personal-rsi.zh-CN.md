# 经济现实中的个人递归自改进

[English](economic-personal-rsi.md)

借来的火越来越强，有限的人应当把自己的时间投向哪里？[个人递归自改进](literary-recursive-improvement.zh-CN.md)使产生改进的方法也能继续改善；经济现实进一步要求选择值得改善的能力。人的学习需要时间，身体需要练习，工具需要维护。某种能力即使能够培养，也要与其他用途比较：自己掌握它、借助模型使用它，或者把精力投入与模型互补的另一种能力，各会带来什么？

## 身体把多种理解接在同一次行动中

人的具身推理贯通视觉、声音、触觉、动作、情感、记忆与语言。拿起一个杯子，同时涉及重量、姿势和用途；听一个人讲话，同时涉及词句、语调、关系历史及眼前情境。参与者会主动改变观察位置、试探一种做法，再根据回应调整。多模态在这里是感知与行动的协调，也是身体与环境持续相遇的方式。

现有机器人研究已经把视觉语言模型接到动作与全身控制。DeepMind 2026 年的 Gemini Robotics 2 报告同时展示了这些进展，以及移动速度、操作精度与速度方面仍需继续改善之处 [[3]](#source-3)。这使本文的近期判断更具体：在多变的真实环境中，以可承担的费用维持广泛、可靠的具身参与，仍是需要逐项实现和检验的能力。

大脑的能量利用为这种培养提供另一项启发。Levy 与 Calvert 的能耗分析区分计算、通信和其他代谢开销，提醒人们常引的约 20 瓦并非单纯的计算功率 [[4]](#source-4)。人的低代谢功耗与丰富感知行动共同存在，值得研究；神经活动怎样换算为机器操作，以及哪种仿真能复现相关功能，则是不同的问题。完整还原大脑与在特定任务上取得相近表现，也有不同的实现要求。

个人已经生活在这套身体与世界的关系中。培养可以从已有的感知、动作和理解继续：通过绘画辨认空间，通过音乐组织听觉与动作，通过制作察觉材料的阻力，通过阅读和实际相遇发展对社会含义的判断。模型展开解释、提供对照、制作工具并整理经验，使本人能够把注意带回值得亲自感知和判断的关系。

## 同一项选择的三种经济考察

神经经济学把价值、风险、等待和选择接到脑与身体的实际过程。Camerer、Loewenstein
与 Prelec 的综述讨论多个系统以及身体状态怎样参与经济选择 [[5]](#source-5)。这份综述
为这里提供的入口，是考察一个选择如何获得价值、如何调动控制，以及条件怎样改变它。
Shenhav、Botvinick 与 Cohen 的「控制的期望价值」理论进一步将预期回报、控制投入
和认知努力成本组织在同一个模型中 [[6]](#source-6)。
这是关于控制分配的一项理论；具体人的判断如何发生，需要相应行为和神经证据。

心理层面的经济考察关心本人怎样体验用途之间的取舍：什么令人愿意投入，什么感到
费力，什么结果值得等待，什么支持真正减轻负担。它与经济心理学、行为经济学和
认知研究相接。Kurzban 等提出用机会成本解释主观努力：同一加工机制用于当前任务，
就暂时放弃了其他可能用途 [[7]](#source-7)。
这项假说让「还有什么值得做」进入努力的解释；疲劳的具体成因仍由身体、任务与
情境的材料判断。主观费力、认知控制与代谢能耗分别描述不同对象，比较时保留各自
的测量与证据。

社会经济层面的考察则问：谁需要这项贡献，什么条件使它能够交换或被支持，收益和
成本怎样分配？可靠完成某项工作、市场愿意为它付费，以及本人认为它值得做，是
相连而各有根据的判断。模型价格、就业要求、合作关系、制度与基础设施，会改变
个人可选择的组合；将监督和维护转交给别人，也改变了整项安排的成本。这样的分工也会改变后来可供选择的机会。

三种考察围绕同一活动相接。例如，用模型完成一段实现，可能降低当下的语言和控制
要求，使本人更愿意继续设计；若同时增加费用或让合作者承担更多核验，整体收益又会
改变。人的体验帮助发现需要解释的差别，研究与实际结果检验解释，社会条件决定哪些
组合可持续。这使资源配置既关注产出，也关注理解、关系、恢复与可自由支配的生活。

### 社会会回应关于自己的模型

社会预测进入社会之后，成为参与者能够利用、反对和适应的条件。招聘标准改变准备方式，推荐改变注意力，评价指标改变组织的行为；这些反应又改变后来用来建模的数据。形式化在这里具有双重作用：它描述某些关系，也通过制度、工具和人的采用参与关系的变化。

Perdomo 等人的「施为性预测」研究把这种反馈表达为预测模型改变目标数据分布，并研究在给定条件下反复训练何时能够稳定 [[2]](#source-2)。这为局部分析提供了形式工具，也使问题更清楚：过去数据上的准确性与介入后的准确性，是需要分别考察的结果。

人的生理与心理状态、彼此的理解、文化意义、资源与制度相互作用，使这种反馈具有多重节律。相同的话在不同关系中可能产生不同后果；人还会创造原先分类没有容纳的新活动。数据能保留其中的痕迹，模型能解释和模拟选定关系，而新的参与继续产生需要重新观察的条件。

因此，本文采用的是**开放且会反过来改变自身条件的建模观**：在说明的范围内形式化，在实际活动中检查，并让对象的变化修订分类与方法。「形式化本身参与变化」给出了这种持续返回的理由；要进一步断言一切社会过程原则上不可计算，则还需要另一个关于可计算性的论证。个人的实际优势，可以来自身处其中、持续感知和行动所获得的关系与校准机会。

## 在真实活动里比较组合

### 先看有限投入怎样组合

经济考察从用途的比较开始。一个下午可以用于亲自练习、借助模型完成作品，或让身体
恢复、把环境维护到容易继续的状态。这些投入能够互相支持，也会占用彼此的机会。
亲自培养可能增加后来能独立辨认和判断的能力；调用模型可能释放时间，并带来核验与
维护工作；休息和支持条件则影响下一次能否开始、持续和返回。组合的价值取决于本人
愿意过的生活及当前真正可行的活动。

| 有限条件 | 比较什么 | 从哪里取得根据 |
| --- | --- | --- |
| 时间 | 当前活动占用了哪些其他用途，节省的时间实际流向哪里？ | 活动经过、交付时间与后续使用。 |
| 注意力与认知工作 | 需要保持多少关系，经历多少切换、监督和恢复？ | 实际操作、本人体验与任务表现。 |
| 身体精力与恢复 | 哪些姿势、感官和动作条件使参与容易维持？ | 身体体验、实际持续及恢复情况。 |
| 费用与可达资源 | 工具、设备、服务和维护是否能持续取得？ | 实际支出、服务条件与可达机会。 |

这些条件各有单位、作用和时间尺度。多买一项服务可能省下操作时间，也可能增加
选择与监督；一小时休息可能改变此后几小时的参与条件。比较先保留各项差别，再按
具体目的形成取舍。图中的箭头表达投入与后果的联系，各条路径可以共同采用。
个人 RSI 进一步比较：下一轮是否更会识别值得投入的活动，更会选择支持，也更容易
完成、恢复或结束。

### 为研究计划保留几种独立的根据

研究计划可以把本人想探究什么、能够怎样持续，与处境中有哪些可能接起来。**兴趣、习惯、能力与经济机会可以分别变化。**兴趣很强时，练习可能仍少；兴趣淡去后，熟悉的惯例仍可能延续。能力有用，却未必有可达的付费机会；新的机会也可能先于相应能力出现。一项变化提供了重新考察其他项的理由，还没有替它们给出答案。

| 方面 | 计划要问什么 | 有用的根据 |
| --- | --- | --- |
| 兴趣 | 哪个问题值得反复回来，为什么？ | 本人表达的关切，以及实际探究时的回应。 |
| 习惯 | 工作在什么条件下能够开始和持续？ | 日常活动中的尝试、中断、惯例与恢复。 |
| 能力 | 本人目前借助哪些支持，能够理解、判断或做出什么？ | 相关作品及具体任务中的表现。 |
| 经济机会 | 哪项贡献具有可达的需求和支持？ | 实际要求、资源、可能的交换与成本。 |

设想一个人对某个研究问题有兴趣，已经有稳定的写作习惯，还需要练习评价证据。模型可以整理来源、做出比较，本人考察其中关键的案例。计划据此选定一份有边界的写作、所需支持和重新评估分工的时机。这项工作是否有经济用途，还要另行调查可达机会。下一次尝试既检验作品，也检验计划是否分清了这些条件。这是区分的实际用法；解释具体的人为什么持续或停下，仍需相应证据。

### 让互补成为可以检验的分工

设想一个人设计供人在移动中使用的界面。他亲自走动、握持设备、辨认环境声和视觉干扰，发现一个静态截图里看不出的操作困难。模型把这种观察展开成候选布局、可运行原型与检查；真实使用再决定哪些变化有帮助。人的贡献来自现场参与和设计判断，模型的贡献使候选更容易生成和实现。

这种分工也会失败。人的直觉可能误判，模型可能遗漏条件，某种练习也可能代价很大而收益有限。比较的对象应是完整活动：取得什么结果，本人后来能够做什么，支持需要多少恢复、监督和维护，以及他人承担了什么成本。

| 值得比较的问题 | 对个人 RSI 的含义 |
| --- | --- |
| 模型已经能可靠承担什么？ | 把可用能力接成工具，减少重复取得它的成本。 |
| 本人的实际参与增加了什么？ | 发展有贡献的感知、情境判断、表达与行动。 |
| 两者如何相互增强？ | 让人的观察改变模型的候选，让模型的展开丰富人的下一次尝试。 |
| 条件变化后，哪项投入仍值得？ | 根据真实能力、需求和维护成本，重选练习、分工与工具。 |

「短期内较难替代」因而是一项需要随条件更新的判断。某种具身活动难以自动化，仍须结合需求、资源和可达机会判断其经济价值；当模型取得新能力，个人也可以转向新的互补关系。生活中的值得，还包括表达、理解、关系与自由支配的时间。

## 容易复制的能力与值得培养的能力

### 从可复制性判断培养方向

任务的输入、操作和成败条件越容易在计算机中表示，候选越容易低成本生成和检查，就越容易形成大规模训练、搜索与复制的条件。规则明确的数字任务，可以让许多尝试在短时间内发生；每次改进又能被分发到大量使用者。个人若把全部学习时间投入重复这些已经廉价可得的操作，就要面对工具能力继续进步的机会成本。

这条关系涉及任务的结构。易于形式化提高了自动化的可行性，是否发生经济上的替代，还取决于可靠性、部署费用、责任、需求与工作怎样重新组合。Autor 对工作自动化的分析强调，机器替代某些任务，也可能提高与它们互补的人的贡献的价值；一种职业内部往往同时包含多种任务 [[1]](#source-1)。

比较优势由这种组合形成。一个人即使在某项数字操作上仍有优势，也可能通过调用模型，把时间转向更有贡献的观察、选择和创作。基础知识仍参与这种分工：理解模型在做什么，识别关键错误，把结果接入现实，都可能需要本人保有足够的概念与练习。值得培养的深度，由这些实际用途决定。

### 摊销怎样颠倒个人培养推理能力的轻重次序

过去，人即使能凭经验发现一个问题，用自己的话解释它，也常常要学会形式化、推导和实现，才能把这个想法做下去。此时最值得补的是形式推理能力：它一旦不足，前面的直觉再好也很难取得可检验的结果。今天，如果形式推理可以从模型那里快速、廉价地取得，情形就倒了过来。能不能从实际遭遇中发现值得推的问题，能不能用自然语言说出理由，能不能在几套都说得通的解释之间察觉哪一套误解了现实，反而更决定这项工作能走多远。**对个人而言，亲自发展形式推理能力与亲自发展具身推理、自然语言推理能力的重要性，由此发生了颠倒。** 要说明这个颠倒，还须解释为什么同一种技术进步会使两类练习的收益朝不同方向变化。

#### 为什么形式推理的价格也会下降

一种能力很难形成，使用它却可以很便宜。人经过多年训练才掌握的翻译、编程与形式推理，过去往往只能通过再训练一个人，或购买已经受过训练的人的时间来取得。软件先改变了其中一部分：写出程序的代价可以分摊给以后所有调用它的人。语言模型又把这件事向前推进了一步。训练所得保存在可复制的参数中，同一套能力可以用在许多使用者的新任务上。它还能够读懂各次任务之间的差别，把已会的功能重新组合起来。个人为一次使用付出的代价，由此可以远低于自己从头学习、编写和操作整套方法的代价。

为什么把形式推理也算在内？因为其中相当一部分工作能够写成可传递的符号操作。一个猜想可以有几种形式化；选定前提以后，可以展开推论，寻找证明或构造反例；得到了候选证明，还可以核查每一步是否成立。模型在训练中习得的表达、搜索和构造能力能反复用于这些工作。一次任务中，不同推导还可以并行展开，某一路发现的反例又可以用来淘汰其他路线。这里有两种收益：训练的形成成本摊到众多使用之中，并行则缩短一次探索的等候时间。一次证明仍要完成，一次近似仍要核验，训练本身也很昂贵。改变的是个人取得这种形式能力所面对的价格，以及亲自再练一遍能够带来的额外收益。

#### 为什么产出越便宜，人反而可能越累

读者也会从训练中获益。熟悉一种表示以后，原先要分几步理解的关系，可以一眼认出。既有知识使阅读更容易，每段新文字却仍要有人读。遇到一个新的论证，人仍须辨认它在说什么，把结论同依据联系起来，再判断所用前提是否符合眼前的情境。前提散在几个地方时，读者还得暂时记住第一处，去找第二处，回头确认两处所指是否相同。这部分代价由这一次阅读的人、在这一次活动里付出。**模型能把形成能力的成本分给众多使用者；读者无法把自己此刻理解一段新文字所需的注意，以同一种方式分给别人。**

这就解释了为什么“模型生成，人来审阅”会遇到困难。生成速度提高以后，同一时间里可供审阅的论证反而更多。若每一种候选、每一步推导都须由人读完才能决定下一步，增加模型的并行能力，就把更多串行工作集中到了一个读者身上。更棘手的是，几条推导可以共同采用一个误解了处境的前提。人即使逐步确认它们都推得出来，也只确认了该前提的后果。要发现那个误解，仍要把前提带回它原先试图解释的事。让人花大部分精力核查形式，还可能挤掉他做这项判断的时间。于是，模型一侧的生产成本下降，与整场活动所耗的心力上升，可以同时发生。

#### 为什么形式能力越容易借用，具身与自然语言推理越值得培养

人生活在语言所指的世界中。语调、动作、身体的迟疑、先前的相遇和眼前的后果，可以一起影响一个判断。人有时已经察觉两种说法落到现实里有差别，却还不能把差别完整地写出来。若合作要求人先列齐实体、关系、条件和例外，才能请模型做事，那么模型最擅长的翻译与组织，恰好被列为人获得帮助的入场条件。接着，若模型又交回一份须由人从头重建的长推导，人便在入口和出口各付了一次转换的代价。

双方可以换一个起点。人指出自己察觉到了什么，提出暂时的解释；模型把它展开成可比较的读法，明说每种读法用了什么前提，推到什么后果，寻找在哪个条件下它们会给出不同判断。人带着这个条件再去看、听、尝试，新的观察便有机会修正双方都接受过的前提。这样经过形式化再返回，人下一次也许更容易直接认出那个区别。用自然语言提出理由、接受反例、修改自己的说法，在这里正是值得练习的推理。模型的形式能力越容易调用，这种练习就越能及时得到有内容的反馈。

#### 两种练习的机会成本

凡是已经写成文字的材料，都可以成为再加工的对象。同样的含义可以换一种语言，长推导可以展开成逐步证明，也可以抽出决定结论的条件；几段彼此依赖的话可以并排，关系也可以画出来。哪一种翻译保留了关键差别，还要依目的检查。正因为转换可以交给模型反复做，而且在许多文字任务上比人自己做更快、更便宜，原材料有多复杂，便不再决定使用者眼前必须处理多少复杂性。环境可以保存详细材料和完整推导，同时把当前判断所需的前提、差别与后果放在一起。

这改变了个人练习的机会成本。人若多花一小时练习手工完成环境已经能可靠提供的文字转换，所得的收益就限于必须亲自做这项工作时省下的时间。若把同一小时用于观察、尝试、提出猜想，或用自己的话把一个理由论证到底，增长的能力却可以同模型已经具备的形式能力结合，改变以后能提出什么问题、能发现什么错误、能做出什么作品。从培养人的推理能力来看，专门与模型竞赛文字加工的速度没有意义。借用它的速度来发展自己的判断，才使摊销给众多使用者的能力，在一个有限的人身上取得了新的用途。

**本文选择的方向，是培养具身、多模态与现实情境中的推理能力，把模型已经能够可靠提供的能力接成工具，并随技术和社会变化重新安排分工。**这种个人 RSI 以生活中的实际所得为尺度，让有限投入能够积累成可继续使用的理解、判断与行动。

## 改善选择投入的方式

递归的对象进一步落到选择本身。一次项目发现，真正限制结果的是对使用情境的理解，下一轮就改变观察和取材；一次工具进步释放了实现时间，就调整练习与分工；一次失败显示原来的评价只计算产量，就把可继续的判断能力与维护负担带入比较。

这让四种能力形成新的内容：建模理解人与工具在当前经济社会条件下怎样贡献，模拟展开不同投入和分工的后果，评估比较实际所得与机会成本，修改改变下一轮怎样学习和合作。后续活动再检验这些选择方法是否变得更好。

**借模型的能力扩展身体与判断，让现实中的参与继续改变使用模型的方法。**个人由此能够在变化的经济环境里发展自己的贡献，也保留重新选择什么值得发展的余地。值得维系的生活，为这项递归提供持续可修订的方向。

[个人递归自改进中的认知分工与负反馈](cognitive-complexity.zh-CN.md)把这项分配带入活动本身：哪些关系值得理解并练习，哪些需要时检索，哪些交给模型，以及后来的参与怎样修订这项选择。
