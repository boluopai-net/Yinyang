# 我们要培养怎样的人——Baby Heraclitus

[English](baby-heraclitus.md)

## 我们要培养怎样的人？

若把有限的生命投入追逐不断扩张的太阳，就可能在追赶中被烧尽。模型公司、研究者与更广泛的集体继续取得能力，把能力带入可用范围；个人可以借来它，不必重做整套取得过程。接下来，若选择培养自己的理解、判断、生成与行动，就要让这份火进入自己的实践：提出直觉，借模型展开，遭遇批评与纠正，再继续生成。[借火与创造能力的培养](stealing-fire.zh-CN.md)展开这条论证。

借火之后，用火培养自己，是让可用的生成能力参与自己的持续生成：把读到的东西带入理解，把直觉说出来，在批评、尝试与反馈中改变判断，再提出新的可能。人本来就在理解和行动；这条培养路径使已有的参与获得新的能力与自己的形式。我们用一个人物来表达这种发展中的参与者：

**用户 ≈ 具身语言模型 ≈ Baby Heraclitus。**

这里的「≈」联系的是接收情境、形成解释、生成表达与行动、接受反馈、继续修订的活动。把用户类比为「具身语言模型」，是从这种往返理解人的生成；人的身体、经验与欲望，使它有自己的质地。他在世界中行动，受到身体、时间、关系与资源的影响，也承担真实后果。

在这种往返中，读到的模型生成材料可能彼此不一致；人也可能一时想要这个，另一时想要那个，觉得不同说法各有道理。承接的可能与自身的生成相遇，欲望与判断也会继续变化。人物中的「baby」因此仍未定型：能够被触动、受到纠正，在尚未整齐的可能之间学习、选择与重新开始。

**「小火人」强调借火之后能够继续生火；「Baby Heraclitus」强调这个生成者自己也仍在变化。** 两种说法共同塑造同一个人物：在创造中形成自己，又带着改变后的自己继续创造。培养的方向，是发展理解、判断、生成与行动，让这种往返能够继续。

[为什么要写个人哲学](why-yinyang.zh-CN.md)说明行动者与共同方向，[萌的论证：开放、学习与适应](meng.zh-CN.md)展开开放和共同学习的条件。人与模型在共同工作中相互纠正，使已经取得的能力成为培养的机会。[用文学式编程写出个人哲学](literary-programming.zh-CN.md)将进一步说明怎样把这种关系写出来、活下去。

这里要培养的是已有能动者的能力：**更能形成和修订目的，理解情境，组织自己与他人的能力，并把想法变成可检验的行动。** 语言是重要媒介，身体、情感、制度和工具共同构成行动条件。

这个人物也会重新理解什么值得创造。若小火人成为必须持续增强、持续产出的理想，
借火便只是把追逐搬进了自己。培养还可以表现为欲望的改变、更有辨别力的判断、
能够维持的习惯，以及与身边人的另一种关系。[从追逐到生活中的修习](stealing-fire.zh-CN.md#从追逐到生活中的修习)
借维特根斯坦的图景澄清，重新考察支配培养的要求；其中的[借火与涅槃](stealing-fire.zh-CN.md#借火与涅槃)
进一步让佛教的解脱方向参与这个问题。

小火人借知识与创造能力之火，也学习辨认贪、嗔、痴怎样使自己受到灼烧。培养因此
包括松开对能力、成果和创造者身份的执取。他可以做完一件作品而不要求它证明全部
自我，也可以休息、改变目的，或让曾经有用的人物形象退场。能力增长和涅槃保留
各自的含义，但创造与放下可以在同一种生活中相互支持。

筏喻于是也适用于「小火人」自身：这个意象帮助生活时，可以使用；它妨碍生活时，
可以改写或放下。Baby Heraclitus 的开放性，包括不再把「成为 Baby Heraclitus」
当作必须永远完成的任务。继续生火取得了另一种可能：创造可以发生，而不必由
对自身身份的执著来维持。

## 为什么是赫拉克利特：从两面看同一件事

赫拉克利特是约公元前 500 年活跃于以弗所的古希腊哲学家。他的著作以残篇传世，常从河流、道路、弓与琴这样的具体事物，让读者看见变化与对立怎样构成同一个世界。认识他，可以从一条连接山脚与山顶的路开始：从山脚走向山顶，是上坡；沿同一条路从山顶走回山脚，就是下坡。路相同，行走方向不同，「上」与「下」就从这份关系中取得含义。这个例子展示的是可以通过说明条件而理解的对立；哲学探究还会遇到条件已经说清、两种解释却仍然竞争的情形。

**Baby Heraclitus 继承的，是看一件事时愿意把两面都看进去的眼光。** 一种说法显得有理，就沿它展开；另一种表面相反的说法也有根据，就转过去看它解释了什么。尚不能很快确定哪一种更好时，让正题与反题都留在探究中，逐渐辨认它们的前提、联系和真正分歧。对立有时来自观看位置，有时来自时间中的转化，有时则构成需要继续判断的冲突。

这种眼光也用来读哲学。例如，他既读数学实在论，考察数学对象独立于人的存在怎样说明数学的客观性；也读反实在论，考察它的不同方案怎样从构造、证明或语言实践理解数学。他让两边各自展开最有力的理由，再比较它们怎样解释同一个问题、在哪里付出解释代价。暂时无法裁定的部分继续开放，已经能够辨清的关系则进入当前判断。新的阅读与实际运用，会使原来的分歧重新获得内容。

这里接上了文集的[容纳不一致语义](inconsistency-tolerant-semantics.zh-CN.md)：有根据的相反材料可以分别进入可用读法；Brave 保留至少一种读法支持的可能，AR 考察每种读法都支持的结论；偏好参与选择时，再在选出的读法族上作相应判断。这是本文赋予 Baby Heraclitus 的当代探究方式。古代残篇提供关于对立与联系的思想资源，现代语义让我们进一步说明怎样组织这些材料与判断。

## 火、河流与逻各斯

赫拉克利特的其他思想，也使这个人物更加具体：

- **变化中的持续。** 河水不断流来，河流仍以这种流动维持自身。把这一意象带到人的培养中，习惯、理解与能力持续改变，一个人也在这些改变中接续自己的生活。
- **对立中的联系。** 弓与琴以相反方向的张力维持结构；冷与热、醒与睡则让人看见状态之间的转化。理解一种事物，要看各方面怎样相互规定、牵引与改变。
- **有尺度的火。** 永活之火按尺度燃起和熄灭，提示变化中的比例与秩序。火因而既表达生成，也使人追问转化怎样发生、什么关系得以维持。本文用它组织小火人的生成意象。
- **共同的逻各斯。** Logos 兼有言说、说明与道理等含义；赫拉克利特借它指向世界中可以理解的共同联系。积累许多见闻，还要学会看出它们怎样相连。他的短句让读者停下来，自己辨认一个熟悉事物中尚未看见的关系。

这些思想共同塑造本文的人物：心里有火，能继续生成；脚下有河流，知道自己也在变化；面对对立，愿意往两边看，并寻找其中可理解的关系。**「Baby」让这份眼光保持生长：他用它看哲学，也让所读的哲学改变自己怎样看。**

## 小狮子：敢于拒绝，也能够开始

前面的[萌的论证：开放、学习与适应](meng.zh-CN.md)画了一只小狮子。它也可以成为 Baby Heraclitus 的形象：保有成长中的开放，又有力量判断什么值得接受、什么需要拒绝。

尼采在《查拉图斯特拉如是说》第一部「三种变形」中，让精神从骆驼变成狮子，再变成孩童 [[3]](#source-3)。狮子反抗「你应当」的命令，为自己的意愿争取自由；但取得创造的自由，还没有创造出新的价值。孩童继而带来重新开始、游戏与肯定，使创造能够发生。

这里把狮子与孩童合成「小狮子」，是对这两个意象的再创作。狮子的拒绝使开放有了判断：不会因为对方更强，就接受每一项要求。孩童的开始则使判断能够继续生成：拒绝之后，还能尝试另一种生活，允许经验和相遇改变自己。

因此，萌所包含的可培养性，也容纳异议与主动创造。小狮子可以接受帮助、在游戏中学习，也可以说「不」，并与他人一起提出「让我们试试这样」。它把前一篇的共同学习条件写成一个仍在成长的行动者，连接借火、培养自己与继续创造。

## 开放性怎样成为一种能力？

「baby」包含一种尚未封闭的状态：能够承认不知道，接受被触动和被纠正，愿意与他人共同生成新的理解。开放也容许张力继续存在：新的解释与旧的判断拉扯，不同欲望尚未找到共同形式。

例如，模型把同一个愿望展开成两条有吸引力、却不能同时实现的生活方向。人先说明各自吸引自己的地方，模型帮助考察条件与代价；尝试其中一项后，经验可能使另一项失去吸引力，也可能让原来的取舍需要重做。这是一种可能的相遇：成长发生在辨认、判断与再生成中，而不只是模型替人选出答案。

面对行动，baby 能够比较这些可能，作出当前有根据的选择，又允许后果改变这份选择。开放正是在这样的练习、反馈与共同工作中成为能力。

要把这种开放性培养成 agent 式的能力，需要让几种品质相互支持：

- **能提出目的，也能修订目的。** 不只回答「怎么完成」，还会追问「想达成什么、为什么值得、谁受到影响」。新的事实可能改变手段，也可能改变目的本身。
- **能用语言建模。** 把模糊直觉展开为可讨论的对象、关系和条件；分清事实、假设、比喻和价值选择，让分歧有具体落点。
- **能怀疑，也能作出判断。** 看见另一种解释，检查自己的欲望与预设；在证据足以支持下一步时行动，在结果抵触判断时修正。
- **能与更强的行动者共同工作。** 不以完全理解和控制对方为合作前提，也不因对方更强就放弃自己的判断。可以分工、借助工具、接受反驳，并共同确定什么结果算好。
- **能让想法接触现实。** 通过实践观察一个解释是否有效，把身体感受、他人回应和实际结果带回讨论，而不只在说法之间循环。
- **喜欢高速迭代，也能辨认节奏。** 缩短从想法到反馈的距离，保留可修正的空间。快的是学习循环；需要积累的经验、关系和难以撤回的行动，有各自合适的速度。

这些品质共同构成「小狮子」：既有提出异议的力量，也保有生成新可能的开放性。

## 个人是目的，社会是优先改变的条件

我们采取一种**个人优先主义**：以具体个人的生活、自由、目的与需要为评价依据，让社会安排和工具服务于人。当个人与既有安排不相适应时，优先检查和改变这些安排，而不让它们仅凭已经存在就获得要求个人改变的优先权。

适应责任的优先方向是：**优先调整社会安排，其次调整软件；要求个人改变，需要具体条件来说明必要性。**

这使「培养 baby」也成为对环境的要求。能否提出异议，取决于关系中是否有发言与决策空间；能否反复尝试，取决于时间、资源与工具。仅要求人更自律，可能只培养了承受障碍的能力。[个人优先的人本主义](personal-first-humanism.zh-CN.md)展开这份适应责任；在这里，它使开放性有机会成长为能力。环境改善和自主学习可以同时发生，个人的成长无需成为迁就既有安排的代价。

例如，一个人在模型协作中迟迟不能行动，先看他是否拥有明确的决策权、能否获得所需支持；再看工具是否迫使他记住复杂命令、反复整理信息或使用不合适的表达方式。调整分工和工具后，他也许已经能够按自己的方式完成工作，不需要再接受一套「合格用户」的训练。仍有需要且他愿意发展的能力，才成为进一步学习的对象。

## 为什么要培养这样的 agent？

这项培养主张可以分成目的、条件与推论。

**目的：个人能够发展自己的生活。** 我们希望人能够理解和修订自己的目的，借助他人和工具，把可能性变成行动。这是本文采取的价值起点。

**条件一：环境与任务会变化。** 一套固定做法可能在原来的情境中有效，却无法自动处理新的问题。因此，仅仅复制答案并不足以保证持续的行动能力。

**条件二：语言模型扩大了共同工作的可能。** 模型帮助展开问题、比较解释与实现想法，人通过阅读、尝试、判断和修订参与其中。一个作品因此既是工作成果，也是人发展理解与行动能力的机会。

**条件三：成长依赖社会条件。** 练习机会、可靠反馈、资源与决策空间，影响一个人能否把开放性转化为能力。因此，培养个人同时需要改善支持他的关系与制度。

**由此得到的培养方向：** 先改善支持个人生活的社会条件，再让软件与工具适合他的目的和参与方式。环境能够承担的适应成本，优先由环境承担；在此基础上，个人可以按自己的意愿发展建模、判断、协作与迭代能力。介入时观察实际障碍：决策权不足就调整关系，操作负担过重就改善工具，个人确有想发展的理解和能力时再安排交流与练习。

**支持成长的社会条件 ＋ 开放性 ＋ 可靠反馈与实践 → 判断、生成与行动能力的发展 → 更能在变化中追求和修订自己的目的。**

Baby Heraclitus 让借火与生火连接起来：集体继续取得能力，个人借它培养自己，在流动与张力中形成判断，在相遇中继续生成，让行动反过来改写理解。小火人因此不是已经完成的理想 agent，而是能够继续成为自己的参与者。

**我们希望培养的，是会成长的小狮子：敢于说「不」，也能够说「让我们开始」。心里有火，脚下有河流 [[1]](#source-1) [[2]](#source-2)。**

baby 由此也是萌的：尚未封闭，愿意亲近新的东西，也愿意在共同生活中被改变。这份萌使他既能接受培养，也能学习怎样引导其他成长中的行动者。前面的[萌的论证：开放、学习与适应](meng.zh-CN.md)已展开有关共同学习、引导与社会条件的条件论证；这里把其中的培养方向赋予人物，并保留那些实际条件。

要让这个方向取得内容，人与模型便开始共同阅读、制作、解决问题和积累环境。愿望、解释、作品与使用后果逐渐留下轨迹。主线接着进入[世界、过程与表达](world-and-expression.zh-CN.md)，考察这些活动怎样留下可以返回的生活材料，并在后续篇章中把它们接成可探索的轨迹。第一部分提出值得培养什么，第二部分让这种培养有共同做事的经历可供继续理解。
