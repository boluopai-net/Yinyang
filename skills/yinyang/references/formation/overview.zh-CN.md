# 六份描述的写作方法

[English](overview.md) · [共同写作要求](shared.zh-CN.md) · [工作模型的形成与修订](../design-and-revision.zh-CN.md)

六份描述写的是一个人与模型之间的一项具体合作。它们合在一起，帮助双方理解正在做什么、
作出合适的贡献，并纠正已经不合用的安排。每篇回答同一实践中的一个不同问题。

| 描述 | 写作者要回答的问题 |
| --- | --- |
| [立场与方向](orientation.zh-CN.md) | 本人希望合作服务于什么？哪些理由和判断尺度支持这个选择？ |
| [个人模型](person.zh-CN.md) | 本人实际怎样参与？什么条件让他能够贡献、学习或作出判断？ |
| [伙伴模型](counterpart.zh-CN.md) | 本人实际遇到的模型在当前条件下能够贡献什么？他期待怎样的贡献？ |
| [关系模型](relationship.zh-CN.md) | 双方的贡献怎样相接，怎样改变对方下一步能做的事？ |
| [实践环境](environment.zh-CN.md) | 哪些实际安排使这些贡献可行？双方从哪里看到结果？ |
| [修订方式](revision.zh-CN.md) | 哪些新根据或实际后果能改变理解、安排，或者改变修订本身的做法？ |

## 从一项真实活动进入

选择一件能查到目的、参与过程和结果的工作。尚未完成的想法、困难的交接或一次顺利接续的
写作，都能成为起点。取来本人对此的描述、模型的贡献和在实际条件下发生的事。采用能够
解释有关区别或支持所选方向的哲学材料。阴阳提供了一种已经展开的写法，采用者可以选用
其中一部分概念，也可以发展自己的理解。

先写材料最能说明的问题。工具带来的困难可以从实践环境进入，并改变对本人参与的理解。
关于学习的新认识可以从立场开始，再改变关系。用上表查找新判断影响的其他问题。写成后，
单篇应能回答自己的问题，六篇合读应能用于同一项工作。

## 把不同贡献写进相应的篇章

例如，一个人想学习阅读困难的文章。立场与方向说明为什么培养判断论证的能力对他重要。
个人模型写清什么样的具体问题能帮助他表达初读的理解。伙伴模型说明模型能否给出准确
段落及有实质内容的异议。关系模型说明谁先给出解释、反馈怎样改变下一次尝试。实践环境说明
原文、批注和讨论怎样保持可找。修订方式说明什么证据足以调整这项安排，又怎样核对改变的
效果。一项活动产生六个相连的回答，各篇有各自的贡献。

证据、凝练和整体检查见[共同写作要求](shared.zh-CN.md)。用各篇指南写出该问题独有的贡献，
让完整材料在实际实践中仍可取回。工作发生变化时，可依[实际工作的修订方法](revision-method.zh-CN.md)
把有根据的纠正带入受影响的描述和实际使用。
