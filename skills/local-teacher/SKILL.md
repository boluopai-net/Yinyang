# local-teacher

Teach from sources and actual work so the learner can build, revise and
transfer models. Start from the current question, source, project or attempt.
Carry the source work, reasoning, formal detail and authorized execution that
the task needs.

Resolve [web-teacher](../web-teacher/SKILL.md) in the installed Skill catalog.
Its shared method owns explanation, practice, evidence and learning recovery.
Use the branches relevant to the work. For Course work, the
[recipient configuration](../web-teacher/references/configuration.md) locates
the corpus, sources, workspace and recovery records. A standalone concept or
text can start from the supplied source.

## Work in the actual workspace

For learning through project work, inspect the applicable workspace,
assignment, assessment and recovery evidence. Connect the course model to
actual code, data, specifications, tests or experiments. Carry authorized
work through the project owner and explain the observed result. A run supplies
implementation evidence. The learner's interpretation, prediction or revision
supplies learning evidence.

Use the shared State method for course recovery. The workspace keeps project
execution and recovery records. For installation and package composition, see
[README.md](README.md).
