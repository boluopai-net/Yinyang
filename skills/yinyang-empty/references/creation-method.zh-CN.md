# 实践指南

[首页](../README.zh-CN.md) · [工作模型的形成与修订](design-and-revision.zh-CN.md) · [阴阳的日常协作](https://github.com/boluopai-net/Yinyang/blob/main/skills/yinyang-empty/SKILL.zh-CN.md) · [English](creation-method.md)

想用阴阳做自己的个人递归自改进（RSI），可以从正在做的事或想弄明白的问题入手。一篇文章、一段对话、日常生活中的一个印象，或已经在用的工具，都可以成为起点。哲学正文可以按兴趣选读。

从同一份材料出发，你和语言模型可以分别凝练出两种东西。**观点**说清一项判断或主张及其理由。**工作模型**说清当事人、伙伴、双方怎样合作，以及这种合作在什么条件下成立、怎样改变。两者各自成立。工作描述用到某条观点时，引用那条观点，再用自己的材料说明它怎样适用于当前处境。

## 从已有材料与实践起步

文章、故事、音乐、设计或程序，都可能表达一个人怎样理解世界、看重什么，以及怎样与他人生活和创作。作品让这些关系取得可以阅读、讨论和修改的形式。你和模型可以从作品、创作过程及其实际后果中理解这些关系。创作和使用作品也可能改变原来的理解。

这里的「哲学」取广义，对理解、价值和做法的反思可以贯穿个人创作。一个故事可以用自己的体裁去表达某种判断。把其中的判断及其理由展开，就能形成可以在别处使用的观点。下表所说的「成文哲学」也包括这样阐明的观点。发展哲学，可以从说清一项作品或实践中已经隐含的理解开始。

这项实践联系着**你的创作、作为创作伙伴的模型，以及双方活动的环境**。哲学帮助说清意义、价值和理由。心理理解帮助解释自己和他人的体验与活动方式。工程把选定的安排变得可用，让它的后果可以观察。三者都可以进入创作、合作和环境。[《哲学、心理与工程》](https://boluopai.net/repositories/prometheus/source/skills/yinyang/references/docs/local-source-and-website.zh-CN.html#哲学心理与工程从已有能力补齐关系)展开了这些联系。

| 已有材料或实践 | 仍需补足的联系与下一项贡献 |
| --- | --- |
| 已有成文哲学或采纳的方向，尚缺具体个人根据和可用的模型环境 | 把哲学与事件历史和日常生活相连，同时准备与模型发展和使用这种理解所需的环境。 |
| 已有相关心理理解、对话或生活材料，尚无成文哲学和可用的模型环境 | 发展有根据的描述，阐明材料支持的判断或主张，同时使所需的模型协助可用。 |
| 已有模型环境和使用经验，个人理解和哲学仍未说清 | 一起解释经验、偏好和概念，说清它们提示的观点，并在使用中修订安排。 |
| 已有成文哲学和有根据的心理理解，尚无可用实现 | 找出一项真实活动中需要落实的关系，把它做成可用的工具或安排。 |
| 已有成文哲学和可用环境，尚缺具体个人根据 | 结合哲学理解对话和生活材料，凝练有根据的个人描述，并从实际使用中修订。 |
| 已有有根据的心理理解和可用环境，哲学仍隐含在实践中 | 展开实践中已经隐含的理解、价值与方向，形成可以讨论和修订的观点。 |

这六种组合说明不同的起步条件。从文学、逻辑、美学或工程哲学入手的写作，都可以推进这项实践，先做什么由已有材料决定。下一步需要的文件、检索、工具、执行或核验条件缺失时，把相关条件补齐。模型可以参与提出问题、比较解释、动手改变安排和查看结果。理解还只是一种暂时解释时，也可以开始做有用的事。

## 从材料形成观点与工作模型

你可以自己写观点，从经验或作品中说清原本隐含的判断，也可以请语言模型从读过的文章中摘出它们提出的观点。你也可以从阴阳的[基本观点](core-views.zh-CN.md)中选择几条，结合其他来源，加上自己的判断。把出处和自己为何采用或改变它说清楚。[《从采用、组合到自己的创作》](https://boluopai.net/repositories/prometheus/source/skills/yinyang/references/docs/example-and-commons.zh-CN.html)展开了几种写法。

形成工作模型时，问同一份材料中有什么会改变你和模型今后怎样合作。材料可以是一项哲学主张、对一段对话的印象、你作过的选择，或亲眼看到的结果。模型可以重建有关历史、比较解释和起草描述。你提供亲历经验、目的、异议和判断。明确说过的偏好可以指导安排，即使它的原因还不清楚。已有安排也可能出于限制或默认值，要进一步判断它能说明什么。

比如，一个人总在同一张桌子前工作，可能是喜欢这个位置，也可能是只在这里能用到所需设备，或者一直没有别的选择。可以问他在确有其他选择时怎样决定，也可以试一次保留所需设备、随时能恢复的变动。如果证据仍支持几种解释，就把条件写进描述。工作位置可以先改善，更广的解释可以留待以后修订。[《工作模型的形成与修订》](design-and-revision.zh-CN.md)说明怎样把这类理解写成六份互相联系、可以用在工作中的描述。

## 哲学与个人环境相互修订

把有根据的关系带入使用。用计算机完成一项工作时，可以说清涉及什么活动、它在什么条件下发生、各步怎样接续，以及能看到怎样的后果。你和模型可以分担提出问题、说明关系、实现和核对结果。文件、界面和工具怎样服务于实际活动，决定了选中的关系能否用起来。[《环境写作指南》](formation/environment.zh-CN.md#在情境中推导行为)展开这种联系。

把与日常工作有关的观点和描述交给模型，例如放进它经常读取的指令。选一件你本来就在做的事，让模型依此调整工具或安排。察觉不合之处，用日常语言提出解释，请模型给出反例，再回到情境中试一试。看什么变得容易，有什么新代价，你学到了什么，这种合作是否支持你想发展的东西，再据此修订相关理解和安排。在不同情境中反复奏效的方法，也可以写成工具或 Skills。

从哲学或从已有工作环境入手，都可以为实践定向。当两边都有可用结果时，也可以用它们改变组织这项工作的办法。如果某种困难反复出现，就修订发现或处理它的方法，在下一次活动里检验能否更早发现问题、更有效地处理。这种返回对强 RSI 很重要，也可以在使用环境的同时培养直觉、具身推理和日常语言推理。[《用文学写出自己的递归改进》](https://boluopai.net/repositories/prometheus/source/skills/yinyang/references/docs/literary-recursive-improvement.zh-CN.html#从改写文字到改变下一轮活动)展开这种机制，并用[阅读例子](https://boluopai.net/repositories/prometheus/source/skills/yinyang/references/docs/literary-recursive-improvement.zh-CN.html#一次阅读怎样改变改善阅读的方法)展示怎样检验方法本身的改变。

### 模型直接写作

把与当前问题有关的材料和要修订的工作描述交给模型，按[如何写六份描述](formation/overview.zh-CN.md)直接整理和凝练。六份工作描述保存在私人的 `references/situated/`，支持材料和来源索引放在 `references/personal/`。[文件与更新约定](package.zh-CN.md#公共内容与情境化内容)说明文件位置。所需版本可以留在私人仓库里。模型能力提升后，可以请它重新理解原材料，改善凝练。

### 可选的记忆与综合辅助

如果检索、整合来源或反复综合成文占了不少工作，也可以使用记忆工具。[Hindsight](hindsight.zh-CN.md)是一种实现，可以保留来源、整合观察，并按问题形成描述。让模型配置和检查工具，把采纳的结果写回六份描述。根据工具能怎样改善实际工作来选择。两种方式都保留六个问题、有归属的根据、六份描述的融贯，以及通过使用继续修订。
